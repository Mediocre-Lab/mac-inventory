# Changelog

## 0.1.0-beta.1 — 2026-10-18

First public experimental prerelease. Adds native inventory search/filter/export, progress and cancellation, saved snapshots, ownership-checked manager previews and explicit removal controls. Includes bounded metadata readers, asynchronous startup, cancellation/result preservation, descriptor-bound manual capture and recovery journals. Adds SemVer, MIT license, installation documentation and DMG packaging.

Known gaps: independent security assessment incomplete; full live-disk/protected-folder coverage, clean-machine runtime portability and other OS/architecture validation remain unverified. Ad-hoc signed; not notarized. Developer-tools Python required.
